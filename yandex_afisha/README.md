Цель разработки дашборда — проанализировать ключевые метрики сервиса Яндекс.Афиша за период июнь-октябрь 2024.
  
При создании графиков для дашборда использовались данные из пяти таблиц: 
- purchases — информация о заказах билетов;
- events — данные о мероприятиях, доступных на платформе;
- venues — сведения о площадках проведения мероприятий;
- regions — список регионов, в которых проводятся мероприятия;
- city — список городов, относящихся к регионам.

Дашборд помогает:
- отслеживать динамику ключевых бизнес-показателей;
- анализировать популярность мероприятий;
- исследовать структуру выручки в разрезе категорий событий и устройств.

Используемый стек: SQL, Datalens.
