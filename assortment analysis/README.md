<b>Студенческий проект: анализ ассортимента методом ABC/XYZ</b>

<b>Цель проекта:</b> оценить структуру ассортимента британского интернет-магазина подарков и товаров для дома и предложить правила управления товарными позициями.

<b>Задачи проекта:</b>

- загрузить данные и проверить их на корректность;
- проанализировать базовую картину бизнеса за исследуемый период;
- провести анализ ассортимента методом ABC/XYZ;
- интепретировать результаты и сформировать список товаров на вывод из ассортимента.

Для реализации проекта была использована информация о транзакционных данных интернет-магазина в период с 2009 по 2011 гг.

<b>Стек:</b> Python (библиотеки pandas, matplotlib), Jupyter Notebook.

<b>Ключевые результаты:</b>

- Проанализирована общая картина бизнеса (уникальных SKU: 4912, уникальных заказов: 39749, уникальных клиентов: 5863, суммарная выручка 2009–2011: 20117964.43, количество проданных единиц:	11193691, средний чек (AOV): 506.13).
- Выявлена ярко выраженная сезонность спроса с ростом в осенние месяцы и в марте.
- Анализ методом ABC подтвердил принцип Парето: 21% товаров из категории A создали 80% общей выручки.
- Всего было сформировано 6 комбинаций товаров: AY, AZ, BY, BZ, CY и CZ. По каждой группе предложена стратегия управления.
- Предложены критерии для отбора кандидатов на вывод из ассортимента: низкий вклад в выручку (менее 0,5%), очень сильная нестабильность спроса (CV > 2), в том числе наличие нулевых продаж в месяце, малое количество уникальных заказов (менее 300), малое количество уникальных клиентов (менее 300).
- Критерии были применены ко всем 4912 SKU, в результате чего выявлены 1039 SKU (21.15% от ассортимента) с долей в выручке 3.17%. Именно их и предлагается проверить на предмет вывода из ассортимента.
