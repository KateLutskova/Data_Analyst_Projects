Цель проекта: проверить гипотезу "Пользователи из Санкт-Петербурга проводят в среднем больше времени за чтением и прослушиванием книг в приложении, чем пользователи из Москвы".

Для анализа использовались таблица `yandex_knigi_data.csv` с данными о пользователях из Москвы и Санкт-Петербурга и их суммарном количестве часов прослушивания/чтения книг.

В работе были использованы библиотеки: pandas, SciPy, NumPy, Matplotlib и statsmodels.
