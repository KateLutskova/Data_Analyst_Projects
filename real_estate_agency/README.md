Цель разработки дашборда — определить наиболее привлекательные сегменты недвижимости Санкт-Петербурга и городов Ленинградской области, а также понять сезонные тенденции, чтобы знать периоды с повышенной активностью продавцов и покупателей недвижимости в регионе.

При создании графиков для дашборда использовались данные из таблиц:

- advertisement — информация об объявлениях;
- flats — информация о квартирах;
- city — информация о городах;
- type — доп.информация о городах.

Дашборд помогает:

- отслеживать динамику объявлений и их содержание;
- исследовать наиболее привлекательные локации;
- выбрать сегмент недвижимости с высоким спросом и подходящий сезон для публикации объявлений;
- спланировать эффективную бизнес-стратегию.

Используемый стек: SQL, Datalens.
